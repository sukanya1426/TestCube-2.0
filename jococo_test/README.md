**Full documentation:** [INSTRUMENTATION.md](INSTRUMENTATION.md) — requirements, setup, instrumentation, device install, collection, TestCube integration, config reference, troubleshooting, and a complete end-to-end example.

Quick start:

```bash
bash jococo_test/setup.sh
python jococo_test/scripts/instrument_apk.py apks/your.apk
```
