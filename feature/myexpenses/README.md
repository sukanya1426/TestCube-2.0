# MyExpenses

Package: `org.totschnig.myexpenses`
Version documented: 4.1.0.2
Source: Official My Expenses documentation (faq.myexpenses.mobi) and in-app menus

> Note from the dataset: My Expenses ships as a free version with Contrib, Extended and Professional in-app upgrades. Features restricted to a paid tier are labelled inline.

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

MyExpenses exposes 46 documented user-facing features, including create an account, edit or delete an account, hide or reorder accounts, view the aggregate (all accounts) balance, record an expense, record income.

## Capabilities

- Create an account
- Edit or delete an account
- Hide or reorder accounts
- View the aggregate (all accounts) balance
- Record an expense
- Record income
- Record a transfer between accounts
- Create a split transaction
- Use the built-in calculator for amounts
- Attach a picture or file to a transaction
- Scan a receipt with OCR
- Add tags to a transaction
- Manage the tag list
- Set the transaction status (cleared/reconciled)
- Create a template for a recurring transaction
- Create a plan (schedule) for a template
- Apply a template manually
- Manage categories
- Import a predefined category set
- Manage parties (payees and payers)
- Create and track a budget
- Review budget progress
- Track debts (money lent and borrowed)
- Filter the transaction list
- Search transactions by text
- Group the transaction list by period
- Sort the transaction list
- View the distribution chart
- View the history chart
- Print a report to PDF
- Export data to CSV, QIF or JSON
- Import data from CSV
- Import data from QIF or other formats
- Create a backup
- Restore from a backup
- Schedule automatic backups
- Set up cloud synchronisation
- Protect the app with a password or the device lock
- Manage currencies and exchange rates
- Add a home screen widget
- Configure the user interface
- Configure transaction entry defaults
- Manage payment methods
- Reset an account (delete its transactions)
- Upgrade to a paid tier
- Open help and the FAQ
