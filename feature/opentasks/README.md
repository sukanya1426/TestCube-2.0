# OpenTasks

Package: `org.dmfs.tasks`
Version documented: 1.4.2
Source: Official OpenTasks repository documentation and F-Droid listing

> Note from the dataset: OpenTasks stores tasks in the Android task provider. Remote synchronisation is performed by a separate sync adapter such as DAVx5; OpenTasks itself does not contain sync accounts.

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

OpenTasks exposes 31 documented user-facing features, including create a task, set the task title and description, set a due date and time, set a start date, set the task priority, set the classification/privacy level.

- Create a task
- Set the task title and description
- Set a due date and time
- Set a start date
- Set the task priority
- Set the classification/privacy level

- Set the completion percentage
- Add a location to a task
- Add a URL to a task
- Add a checklist to a task
- Set an alarm/reminder
- Create a recurring task

- Delete a task
- Browse tasks grouped by due date
- Browse tasks grouped by start date
- Browse tasks grouped by list
