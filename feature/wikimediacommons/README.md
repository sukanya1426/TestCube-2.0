# Wikimedia Commons

Package: `fr.free.nrw.commons`
Version documented: F-Droid build 1066
Source: Official Wikimedia Commons Android app documentation and F-Droid listing

The official app for uploading freely-licensed media to Wikimedia Commons. It
takes photos or picks them from the device, attaches a title, description,
categories, depictions and a licence, then uploads them. It also browses nearby
places that need photographs, shows the user's own contributions and their
status, supports a custom upload queue with retry, and offers a map and an
explore feed of existing Commons media.

Uploading requires a Wikimedia account; browsing, nearby places and explore work
without signing in.
