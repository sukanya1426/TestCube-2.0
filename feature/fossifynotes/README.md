## What the app does

Fossify Notes exposes 29 documented user-facing features, including create a text note, create a checklist note, tick and untick checklist items, reorder or remove checklist items, switch between notes, rename a note.

## Capabilities

- Create a text note
- Create a checklist note
- Tick and untick checklist items
- Reorder or remove checklist items
- Switch between notes
- Rename a note
- Delete a note
- Undo and redo edits
- Search inside a note
- Lock a note with a PIN, pattern or fingerprint
- Unlock a protected note
- Export a note to a file
- Export all notes at once
- Import a note from a file
- Keep a note synchronised with a file on disk
- Share a note
- Print a note
- Add the note home screen widget
- Change the editor font size and typeface
- Enable or disable line wrapping
- Set where the cursor is placed when a note is opened
- Configure checklist behaviour
- Show a word and character count
- Set the note text alignment
- Enable automatic saving
- Protect the whole app with a lock
- Customise the app colours and theme
- Change the app language
- View the about screen, FAQ and licences
