# Vinyl Music Player

Light and slick material-design music player. Easy to use and customizable (multiple themes including a dark one). Supports folder browsing, sleep timer, and a tag editor. Forked from Phonograph.

- Package: `com.poupa.vinylmusicplayer`
- F-Droid: https://f-droid.org/en/packages/com.poupa.vinylmusicplayer/
- Source: https://github.com/AdrienPoupa/VinylMusicPlayer

## User-facing capabilities

- Get started and allow media/storage permissions
- Browse and play songs from the library
- Open the currently playing screen from the bottom mini-player card
- Pause, next, and previous from the now-playing screen
- Search the library
- Rescan the music library from the navigation drawer
- Shuffle all from the overflow menu
