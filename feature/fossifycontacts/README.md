## What the app does

Fossify Contacts exposes 38 documented user-facing features, including create a contact, add a photo to a contact, add multiple phone numbers with types, add email addresses, add postal addresses, add important dates (birthday and anniversary).

## Capabilities

- Create a contact
- Add a photo to a contact
- Add multiple phone numbers with types
- Add email addresses
- Add postal addresses
- Add important dates (birthday and anniversary)
- Add the organisation and job title
- Add websites and instant messaging handles
- Add notes to a contact
- Set a custom ringtone for a contact
- Edit a contact
- Delete a contact
- Mark a contact as a favourite
- Remove a contact from favourites
- Call a contact
- Send an SMS to a contact
- Send an email to a contact
- Create a contact group
- Add contacts to a group
- Rename or delete a group
- Send a message or email to a whole group
- Search contacts
- Sort the contact list
- Filter which contact sources are shown
- Choose which fields are visible in the contact detail
- Show only contacts with phone numbers
- Merge duplicate contacts
- Share a contact as a vCard
- Export contacts to a vCard (.vcf) file
- Import contacts from a vCard file
- Create a home screen shortcut to a contact
- Choose the default tab shown at start-up
- Show or hide the individual tabs
- Customise the app colours and theme
- Protect the app with a PIN, pattern or fingerprint
- Change the app language and font size
- Show contact thumbnails and phone numbers in the list
- View the about screen, FAQ and licences
