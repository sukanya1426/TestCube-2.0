# RadioDroid

Package: `net.programmierecke.radiodroid2`
Version documented: 0.86
Source: Official RadioDroid repository documentation and F-Droid listing

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

RadioDroid exposes 32 documented user-facing features, including browse popular radio stations, search for a station by name, search stations by tag, country, language or state, play a station, stop playback, add a station to favourites.

## Capabilities

- Browse popular radio stations
- Search for a station by name
- Search stations by tag, country, language or state
- Play a station
- Stop playback
- Add a station to favourites
- Remove a station from favourites
- Reorder favourite stations
- View station details
- Vote for a station
- Open a station's homepage
- Share a station
- Record the stream to a file
- Browse and play saved recordings
- View the played-track history
- Set a sleep timer
- Set a radio alarm clock
- Enable, edit or delete an alarm
- Import favourite stations from an M3U file
- Export favourite stations to an M3U file
- Cast a station to a Chromecast device
- Send playback to an MPD server
- Control playback from the notification
- Choose the media player engine
- Adjust the streaming buffer and resume behaviour
- Set the recordings folder and naming
- Restrict playback or downloads to Wi-Fi
- Change the theme
- Change the station list layout and icon display
- Select the radio-browser server or mirror
- Add the home screen shortcut for a station
- View the about screen and licences
