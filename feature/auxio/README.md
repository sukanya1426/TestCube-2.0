Auxio exposes 34 documented user-facing features, including browse the music library by songs, browse by album, browse by artist, browse by genre, browse by playlist, play a song.

- Browse the music library by songs
- Browse by album
- Browse by artist
- Browse by genre
- Browse by playlist
- Play a song
- Control playback from the expanded player
- Use repeat and shuffle
- Shuffle the whole library
- View and edit the play queue
- Add a song, album or artist to the queue
- Create a playlist
- Add songs to an existing playlist
- Rename, reorder or delete a playlist
- Import a playlist from an M3U file
- Export a playlist to an M3U file
- Search the library
- Sort a list
- View song details and file information
- Jump from a song to its album or artist
- Share a song
- Configure which folders are scanned
- Rescan the music library
- Configure how multi-value tags are separated
- Enable or disable ReplayGain
- Open the system equaliser
- Configure headset and audio focus behaviour
- Choose what the playback bar and notification show
- Change the theme and accent colour
- Choose which library tabs are visible and their order
- Set the playback behaviour when selecting a song
- Add the Auxio home screen widget
- Save and restore the playback state
- View the about screen and licences
