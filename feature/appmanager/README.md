# App Manager

Package: `io.github.muntashirakon.AppManager`
Version documented: 4.1.0
Source: Official App Manager documentation and F-Droid listing

An open-source package manager and viewer for Android. It lists installed and
system packages and exposes each one's manifest, components, permissions,
signatures, trackers and storage use. It can batch-operate on apps (freeze,
force-stop, clear data, uninstall), export rules, inspect app usage statistics,
install and split APKs, and open a per-app details view with tabbed sections.

Root or ADB-over-network access unlocks the privileged operations; without it
the app still browses, inspects, scans for trackers and exports information.
