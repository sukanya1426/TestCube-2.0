# AnkiDroid

Package: `com.ichi2.anki`
Version documented: 2.24.0
Source: Official AnkiDroid manual and in-app menus

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

AnkiDroid exposes 59 documented user-facing features, including create a deck, create a subdeck, rename a deck, delete a deck, reorder or re-parent decks, study a deck.
