# Odyssey

Package: `org.gateshipone.odyssey`
Version documented: F-Droid build 42
Source: Official Odyssey repository documentation and F-Droid/store listing

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

Odyssey exposes 33 documented user-facing features, including browse the music library by album, browse the music library by artist, browse all tracks, browse recently added albums, browse the file system with the file browser, play a track.

## Capabilities

- Browse the music library by album
- Browse the music library by artist
- Browse all tracks
- Browse recently added albums
- Browse the file system with the file browser
- Play a track
- Control playback from the full player
- Use repeat and shuffle
- View and edit the play queue
- Add an album, artist or track to the queue
- Clear the play queue
- Save the current queue as a playlist
- Browse and play saved playlists
- Delete a playlist
- Create a bookmark to resume an audiobook or podcast
- Resume from a bookmark
- Delete a bookmark
- Search the library
- Jump from a track to its album or artist
- View track and album information
- Download artwork for artists and albums
- Clear the artwork cache
- Restrict artwork downloads to Wi-Fi
- Control playback from the lock screen and the notification
- Add the Odyssey home screen widget
- Scrobble to Last.fm through a scrobbler app
- Open the system equaliser
- Change the theme
- Change the library view style
- Change the album and track sort order
- Configure playback behaviour
- Rescan the media library
- View the about screen and licences
