# VLC

Package: `org.videolan.vlc`
Version documented: 3.7.1
Source: Official VideoLAN documentation and in-app menus

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

VLC exposes 46 documented user-facing features, including browse the video library, browse the audio library, browse device folders and storage, browse network shares, add a network share manually, open a network stream from a URL.

- Browse the video library
- Browse the audio library

- Resume playback where you left off
- Control video playback

- Add media to an existing playlist
- Manage the play queue
- Use repeat and shuffle
- Add media to the queue without interrupting playback
- View media information
