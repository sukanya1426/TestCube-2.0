# Open Camera

Package: `net.sourceforge.opencamera`
Version documented: 1.56.2
Source: Official Open Camera help pages (opencamera.org.uk) and in-app settings

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

Open Camera exposes 55 documented user-facing features, including take a photo, record a video, switch between the front and rear cameras, zoom in and out, focus by tapping, change the focus mode.

## Capabilities

- Take a photo
- Record a video
- Switch between the front and rear cameras
- Zoom in and out
- Focus by tapping
- Change the focus mode
- Set the flash mode
- Use the front screen flash for selfies
- Set exposure compensation
- Set the ISO and shutter speed manually
- Set the white balance
- Choose a scene mode
- Apply a colour effect
- Set the photo resolution
- Set the image quality and format
- Capture RAW (DNG) files
- Use the self-timer
- Take a repeated series of photos (auto-repeat)
- Take an HDR photo
- Take a DRO (dynamic range optimised) photo
- Take an exposure bracketing series
- Take a noise-reduction (low light) photo
- Capture a panorama
- Enable face detection
- Enable auto-level (auto-stabilise)
- Show composition guides and crop guides
- Show the histogram, zebra stripes and focus peaking
- Show the angle, level, battery and free-memory indicators
- Enable geotagging of photos and videos
- Store the compass direction with photos
- Stamp the date, time and location on photos
- Add a custom text stamp
- Set the video resolution and frame rate
- Record slow-motion or high-speed video
- Record a time-lapse video
- Set the video bitrate
- Limit the video duration or file size
- Enable video stabilisation
- Choose the audio source and control audio recording
- Record GPS/time subtitles for videos
- Use voice control to take a photo
- Use audio (noise) triggering
- Use a Bluetooth LE remote control
- Configure the volume key behaviour
- Enable touch-to-capture
- Lock the screen orientation
- Use immersive (full screen) mode
- Set the photo and video save location
- Use the Storage Access Framework for saving
- Open the last photo in the gallery
- Pause the preview after taking a photo
- Enable or disable the shutter sound
- Enable the Camera2 API
- Reset all settings to the defaults
- Read the built-in help and about information
