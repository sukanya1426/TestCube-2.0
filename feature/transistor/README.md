# Transistor

Package: `org.y20k.transistor`
Version documented: 4.3.8
Source: Official Transistor repository documentation and F-Droid listing

> Note from the dataset: Transistor is deliberately minimal and has no station discovery feed; stations are added by search, playlist address or raw stream address.

This app is explored automatically by TestCube and by LLMDroid. The list
below is the documented, user-facing capability set; it is context for the
tester, not a script to follow.

## What the app does

Transistor exposes 23 documented user-facing features, including add a station by searching the radio-browser directory, add a station from an M3U or PLS playlist address, add a station from a raw stream address, add a station by opening a stream file in the browser, play a station, stop playback.

## Capabilities

- Add a station by searching the radio-browser directory
- Add a station from an M3U or PLS playlist address
- Add a station from a raw stream address
- Add a station by opening a stream file in the browser
- Play a station
- Stop playback
- View the now-playing metadata
- Delete a station
- Enable station editing
- Rename a station
- Change a station's image
- Change a station's stream address
- Update station information from the source
- Reorder stations in the list
- Set a sleep timer
- Control playback from the notification
- Add a home screen shortcut for a station
- Import stations by copying M3U files into the collection folder
- Back up and restore the station collection
- Choose the playback behaviour on Bluetooth/headphone disconnect
- Change the theme
- Delete all stations (reset the collection)
- View the about screen and licence information
