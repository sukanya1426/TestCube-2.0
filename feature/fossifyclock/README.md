## What the app does

Fossify Clock exposes 26 documented user-facing features, including view the current time on the clock tab, add a time zone to the clock, remove or reorder time zones, open the full-screen (screensaver) clock, create an alarm, enable or disable an alarm.

## Capabilities

- View the current time on the clock tab
- Add a time zone to the clock
- Remove or reorder time zones
- Open the full-screen (screensaver) clock
- Create an alarm
- Enable or disable an alarm
- Edit an alarm
- Delete an alarm
- Set the alarm sound and vibration
- Snooze or dismiss a ringing alarm
- Configure the snooze duration and maximum ring time
- Make the alarm volume increase gradually
- Use the stopwatch
- Sort the recorded stopwatch laps
- Create a timer
- Label a timer and set its sound
- Pause, resume, reset or delete a timer
- Add the digital clock home screen widget
- Set the time format
- Set the first day of the week
- Keep the screen on in the clock tab
- Choose which tabs are visible
- Make alarms ignore silent mode
- Customise the app colours and theme
- Change the app language and font size
- View the about screen, FAQ and licences
